1. Factorial using recursion

GFG link: https://www.geeksforgeeks.org/problems/factorial5739/1

class Solution:
    def factorial(self, n):
        if n <= 1:
            return 1
        return n * self.factorial(n - 1)

Example: factorial(5) = 120. Time O(n), recursion stack O(n).

2. Power of a number using recursion (fast exponentiation)

Syllabus topic: find power of a number.

def power(x, n):
    if n == 0:
        return 1
    half = power(x, n // 2)
    result = half * half
    return result if n % 2 == 0 else result * x

This computes x ** n for n >= 0. Time O(log n), recursion stack O(log n). This is faster than multiplying x by itself n times.

If the linked GFG “Power of Numbers” task asks for n raised to the reverse of n, use its specific required method:

class Solution:
    def reverseExponentiation(self, n):
        rev = int(str(n)[::-1])
        return n ** rev

8. LeetCode — Find Pivot Index

Link: https://leetcode.com/problems/find-pivot-index/description/

Recommended optimal submission (iterative):

class Solution:
    def pivotIndex(self, nums):
        total = sum(nums)
        left = 0
        for i, x in enumerate(nums):
            if left == total - left - x:
                return i
            left += x
        return -1

Time O(n), extra space O(1). Recursion is unnecessary here and does not improve complexity.

9. Remove duplicates from a sorted array

Syllabus link: https://classroom.codingninjas.com/app/classroom/me/21313/content/451415/offering/6582572/problem/91

Recommended optimal solution (iterative two pointers):

def removeDuplicates(arr, n=None):
    if n is None:
        n = len(arr)
    if n == 0:
        return 0
    write = 1
    for read in range(1, n):
        if arr[read] != arr[write - 1]:
            arr[write] = arr[read]
            write += 1
    return write

Time O(n), extra space O(1). This is better than a recursive version because it avoids an O(n) recursion stack. Use the method name and return convention required by your classroom problem.

10. Fibonacci number — recursive version

GFG link: https://www.geeksforgeeks.org/problems/nth-fibonacci-number1335/1

Simple recursion (good for understanding, but slow for large n):

def fibonacci_recursive(n):
    if n <= 1:
        return n
    return fibonacci_recursive(n - 1) + fibonacci_recursive(n - 2)

Time O(2^n) approximately, recursion stack O(n). This demonstrates the recursion tree but is not the best submission for large inputs.

Memoized recursion (faster):

from functools import lru_cache

@lru_cache(maxsize=None)
def fibonacci_memo(n):
    if n <= 1:
        return n
    return fibonacci_memo(n - 1) + fibonacci_memo(n - 2)

Time O(n), space O(n) including cache and recursion stack.

Best simple efficiency for the GFG judge (iterative):

class Solution:
    def nthFibonacci(self, n):
        a, b = 0, 1
        for _ in range(n):
            a, b = b, a + b
        return a

Time O(n), extra space O(1). Use this when the judge has large test cases.

11. Tower of Hanoi using recursion

GFG link: https://www.geeksforgeeks.org/problems/tower-of-hanoi-1587115621/1

The linked GFG problem commonly asks for the minimum number of moves, which is 2^n - 1, rather than printing the moves. For the required GFG method:

class Solution:
    def towerOfHanoi(self, n, fromm, to, aux):
        return (1 << n) - 1

Time O(1), space O(1).

To understand the recursive algorithm and recursion tree, use this version to print every move:

def tower_of_hanoi(n, source="A", auxiliary="B", target="C"):
    if n == 0:
        return
    tower_of_hanoi(n - 1, source, target, auxiliary)
    print(f"Move disk {n} from {source} to {target}")
    tower_of_hanoi(n - 1, auxiliary, source, target)

Time O(2^n) because there are 2^n - 1 moves; recursion stack O(n).

Recurrence relation:

T(n) = 2T(n - 1) + O(1), so T(n) = O(2^n).

10. LeetCode — Maximum Subarray (Kadane's Algorithm)

Link: https://leetcode.com/problems/maximum-subarray/description/

class Solution:
    def maxSubArray(self, nums):
        current = best = nums[0]
        for x in nums[1:]:
            current = max(x, current + x)
            best = max(best, current)
        return best

Time O(n), space O(1).

11. LeetCode — Maximum Product Subarray

Link: https://leetcode.com/problems/maximum-product-subarray/description/

class Solution:
    def maxProduct(self, nums):
        high = low = answer = nums[0]
        for x in nums[1:]:
            if x < 0:
                high, low = low, high
            high = max(x, high * x)
            low = min(x, low * x)
            answer = max(answer, high)
        return answer

Time O(n), space O(1).

class Solution:
    def twoSum(self, nums, target):
        seen = {}
        for i, x in enumerate(nums):
            need = target - x
            if need in seen:
                return [seen[need], i]
            seen[x] = i
        return []

15. LeetCode — Rotate Array

Link: https://leetcode.com/problems/rotate-array/description/

class Solution:
    def rotate(self, nums, k):
        n = len(nums)
        if n == 0:
            return
        k %= n

        def reverse(left, right):
            while left < right:
                nums[left], nums[right] = nums[right], nums[left]
                left += 1
                right -= 1

        reverse(0, n - 1)
        reverse(0, k - 1)
        reverse(k, n - 1)

Time O(n), extra space O(1). This rotates right by k, as required by LeetCode.

class Solution:
    def sortColors(self, nums):
        low = mid = 0
        high = len(nums) - 1
        while mid <= high:
            if nums[mid] == 0:
                nums[low], nums[mid] = nums[mid], nums[low]
                low += 1
                mid += 1

                high -= 1

class Solution:

        left, right = 0, len(height) - 1
        best = 0
        while left < right:
            best = max(best, (right - left) * min(height[left], height[right]))

            else:
                right -= 1

18. LeetCode — Trapping Rain Water

Link: https://leetcode.com/problems/trapping-rain-water/

class Solution:
    def trap(self, height):
        left, right = 0, len(height) - 1
        left_max = right_max = water = 0
        while left < right:
            if height[left] <= height[right]:
                left_max = max(left_max, height[left])
                water += left_max - height[left]
                left += 1
            else:
                right_max = max(right_max, height[right])
                water += right_max - height[right]
                right -= 1
        return water

Time O(n), space O(1).

class Solution:

23. LeetCode — Search in Rotated Sorted Array (distinct values)

Link: https://leetcode.com/problems/search-in-rotated-sorted-array/

class Solution:
    def search(self, nums, target):
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = left + (right - left) // 2
            if nums[mid] == target:
                return mid

            if nums[left] <= nums[mid]:
                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
            else:
                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1
        return -1

Time O(log n), space O(1).

24. LeetCode — Search in Rotated Sorted Array II (duplicates)

Link: https://leetcode.com/problems/search-in-rotated-sorted-array-ii/

class Solution:
    def search(self, nums, target):
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = left + (right - left) // 2
            if nums[mid] == target:
                return True

            if nums[left] == nums[mid] == nums[right]:
                left += 1
                right -= 1
            elif nums[left] <= nums[mid]:
                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
            else:
                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1
        return False

Average O(log n), worst-case O(n), space O(1).

25. GFG — Aggressive Cows

Link: https://www.geeksforgeeks.org/problems/aggressive-cows/0

Common GFG signature: aggressiveCows(self, stalls, k). If your editor shows another signature, keep the editor's exact name.

class Solution:
    def aggressiveCows(self, stalls, k):
        stalls.sort()
        n = len(stalls)
        if k <= 1:
            return 0

        def can_place(distance):
            count = 1
            last = stalls[0]
            for position in stalls[1:]:
                if position - last >= distance:
                    count += 1
                    last = position
                    if count >= k:
                        return True
            return False

        left, right = 1, stalls[-1] - stalls[0]
        answer = 0
        while left <= right:
            mid = left + (right - left) // 2
            if can_place(mid):
                answer = mid
                left = mid + 1
            else:
                right = mid - 1
        return answer

Time O(n log n + n log R), where R is the coordinate range.

26. LeetCode — Spiral Matrix

Link: https://leetcode.com/problems/spiral-matrix/description/

class Solution:
    def spiralOrder(self, matrix):
        if not matrix or not matrix[0]:
            return []
        top, bottom = 0, len(matrix) - 1
        left, right = 0, len(matrix[0]) - 1
        result = []

        while top <= bottom and left <= right:
            for c in range(left, right + 1):
                result.append(matrix[top][c])
            top += 1

            for r in range(top, bottom + 1):
                result.append(matrix[r][right])
            right -= 1

            if top <= bottom:
                for c in range(right, left - 1, -1):
                    result.append(matrix[bottom][c])
                bottom -= 1

            if left <= right:
                for r in range(bottom, top - 1, -1):
                    result.append(matrix[r][left])
                left += 1
        return result

Time O(mn), output space O(mn).

27. LeetCode — Search a 2D Matrix

Link: https://leetcode.com/problems/search-a-2d-matrix/description/

class Solution:
    def searchMatrix(self, matrix, target):
        if not matrix or not matrix[0]:
            return False
        rows, cols = len(matrix), len(matrix[0])
        left, right = 0, rows * cols - 1
        while left <= right:
            mid = left + (right - left) // 2
            value = matrix[mid // cols][mid % cols]
            if value == target:
                return True
            if value < target:
                left = mid + 1
            else:
                right = mid - 1
        return False

Time O(log(mn)), space O(1). Requires the LeetCode matrix ordering conditions.

29. LeetCode — Median of a Row-Wise Sorted Matrix

Link: https://leetcode.com/problems/median-of-a-row-wise-sorted-matrix/description/

from bisect import bisect_right

class Solution:
    def matrixMedian(self, grid):
        rows, cols = len(grid), len(grid[0])
        low = min(row[0] for row in grid)
        high = max(row[-1] for row in grid)
        desired = (rows * cols + 1) // 2

        while low < high:
            mid = low + (high - low) // 2
            count = sum(bisect_right(row, mid) for row in grid)
            if count < desired:
                low = mid + 1
            else:
                high = mid
        return low

Time O(rows * log(cols) * log(value range)), space O(1) auxiliary. This matches the LeetCode matrixMedian method name.

34. GFG — Isomorphic Strings

Link: https://www.geeksforgeeks.org/problems/isomorphic-strings-1587115620/1

class Solution:
    def areIsomorphic(self, s1, s2):
        if len(s1) != len(s2):
            return False
        forward, backward = {}, {}
        for a, b in zip(s1, s2):
            if a in forward and forward[a] != b:
                return False
            if b in backward and backward[b] != a:
                return False
            forward[a] = b
            backward[b] = a
        return True

class Solution:
    def getLPSLength(self, s):
        n = len(s)
        lps = [0] * n
        length = 0
        i = 1
        while i < n:
            if s[i] == s[length]:
                length += 1
                lps[i] = length
                i += 1
            elif length:
                length = lps[length - 1]
            else:
                lps[i] = 0
                i += 1
        return lps[-1] if n else 0

37. GFG — Minimum times A must be repeated so B is a substring

38. LeetCode — Design Linked List

Link: https://leetcode.com/problems/design-linked-list/description/

class Node:
    def __init__(self, val=0, nxt=None):
        self.val = val
        self.next = nxt

class MyLinkedList:
    def __init__(self):
        self.head = None
        self.size = 0

    def get(self, index):
        if index < 0 or index >= self.size:
            return -1
        cur = self.head
        for _ in range(index):
            cur = cur.next
        return cur.val

    def addAtHead(self, val):
        self.head = Node(val, self.head)
        self.size += 1

    def addAtTail(self, val):
        node = Node(val)
        if not self.head:
            self.head = node
        else:
            cur = self.head
            while cur.next:
                cur = cur.next
            cur.next = node
        self.size += 1

    def addAtIndex(self, index, val):
        if index > self.size:
            return
        if index <= 0:
            self.addAtHead(val)
            return
        prev = self.head
        for _ in range(index - 1):
            prev = prev.next
        prev.next = Node(val, prev.next)
        self.size += 1

    def deleteAtIndex(self, index):
        if index < 0 or index >= self.size:
            return
        if index == 0:
            self.head = self.head.next
        else:
            prev = self.head
            for _ in range(index - 1):
                prev = prev.next
            prev.next = prev.next.next
        self.size -= 1

Index operations are O(n); head insertion/deletion are O(1).

class Solution:
    def rotateRight(self, head, k):
        if not head or not head.next or k == 0:
            return head
        length = 1
        tail = head
        while tail.next:
            tail = tail.next
            length += 1
        k %= length
        if k == 0:
            return head
        tail.next = head
        steps_to_new_tail = length - k
        new_tail = head
        for _ in range(steps_to_new_tail - 1):
            new_tail = new_tail.next
        new_head = new_tail.next
        new_tail.next = None
        return new_head

Time O(n), space O(1).

50. GFG — Smaller on Left

Link: https://www.geeksforgeeks.org/problems/smaller-on-left20360700/1

This problem's exact method name can differ by GFG version. The following returns, for every element, the count of earlier elements smaller than it using coordinate compression + Fenwick tree.

class Solution:
    def constructLowerArray(self, arr):
        # Some GFG variants use another method name/return definition.
        # This implementation returns the count of earlier smaller values.
        values = sorted(set(arr))
        rank = {v: i + 1 for i, v in enumerate(values)}
        bit = [0] * (len(values) + 1)

        def query(i):
            total = 0
            while i > 0:
                total += bit[i]
                i -= i & -i
            return total

        def update(i):
            while i < len(bit):
                bit[i] += 1
                i += i & -i

        answer = []
        for x in arr:
            r = rank[x]
            answer.append(query(r - 1))
            update(r)
        return answer

Time O(n log n), space O(n). Check the actual GFG prompt: if it asks for the previous smaller *element* rather than the *count*, this is a different problem.

class Solution:
    def evaluatePostfix(self, S):
        stack = []
        for ch in S:
            if ch.isdigit():
                stack.append(int(ch))
            else:
                b = stack.pop()
                a = stack.pop()
                if ch == '+':
                    stack.append(a + b)
                elif ch == '-':

        return stack[-1]

class MinStack:
    def __init__(self):
        self.stack = []
        self.minimums = []

    def push(self, val):
        self.stack.append(val)
        if not self.minimums or val <= self.minimums[-1]:
            self.minimums.append(val)

    def pop(self):
        val = self.stack.pop()
        if val == self.minimums[-1]:
            self.minimums.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.minimums[-1]

All operations O(1); space O(n).

58. LeetCode — Design Circular Queue

Link: https://leetcode.com/problems/design-circular-queue/description/

class MyCircularQueue:
    def __init__(self, k):
        self.data = [0] * k
        self.capacity = k
        self.front_index = 0
        self.size = 0

    def enQueue(self, value):
        if self.isFull():
            return False
        idx = (self.front_index + self.size) % self.capacity
        self.data[idx] = value
        self.size += 1
        return True

    def deQueue(self):
        if self.isEmpty():
            return False
        self.front_index = (self.front_index + 1) % self.capacity
        self.size -= 1
        return True

    def Front(self):
        return -1 if self.isEmpty() else self.data[self.front_index]

    def Rear(self):
        if self.isEmpty():
            return -1
        idx = (self.front_index + self.size - 1) % self.capacity
        return self.data[idx]

    def isEmpty(self):
        return self.size == 0

    def isFull(self):
        return self.size == self.capacity

All operations O(1), space O(k).

59. LeetCode — Implement Queue using Stacks

class MyQueue:
    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x):
        self.in_stack.append(x)

    def _move(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())

    def pop(self):
        self._move()
        return self.out_stack.pop()

    def peek(self):
        self._move()
        return self.out_stack[-1]

    def empty(self):
        return not self.in_stack and not self.out_stack

60. Stack using Queues (standard implementation)

from collections import deque

class MyStack:
    def __init__(self):
        self.q = deque()

    def push(self, x):
        self.q.append(x)
        for _ in range(len(self.q) - 1):
            self.q.append(self.q.popleft())

    def pop(self):
        return self.q.popleft()

    def top(self):
        return self.q[0]

    def empty(self):
        return not self.q

Push O(n), pop/top O(1), space O(n).
